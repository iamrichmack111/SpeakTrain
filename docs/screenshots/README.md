# Playwright screenshots

The `Refresh documentation screenshots` workflow generates twelve PNG files here from a fresh isolated `admin / admin` database. Run locally with:

```bash
PYTHON_EXECUTABLE=.venv/bin/python npm run screenshots
```

The suite covers login, Today, Phrase Practice, Courses, OPI, Vocabulary Test, Conjugation, Conversation, Vocabulary/Sentence Lab, Progress, Admin, and the weekly report.
