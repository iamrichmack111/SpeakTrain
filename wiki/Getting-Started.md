# Getting Started

## First session

1. Register the first account. It becomes the local administrator.
2. Open **Today** and start the first item in the smart queue.
3. Listen once, shadow once, then answer without reading.
4. Complete at least five items before reviewing Progress.
5. Return when the dashboard says an item is due.

## Recommended daily routine

- 5 minutes: due vocabulary and conjugations.
- 10 minutes: phrase recall with gender and register changes.
- 5 minutes: guided conversation.
- 5–10 minutes: sentence building or an OPI response.

Accuracy comes before speed. WPM is withheld on samples too short to measure meaningfully.

## Speech engines

Browser speech works immediately. Faster Whisper adds local transcription. Piper adds cached local reference voices. See the README for installation and environment variables.
