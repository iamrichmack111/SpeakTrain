# Today Dashboard

Today is the adaptive home page. It combines scheduled reviews with new material instead of asking the learner to choose randomly.

## Dashboard elements

- **Due now:** items whose review time has arrived.
- **Learning/Familiar/Strong/Mastered:** current memory-state counts.
- **Smart queue:** the next recommended actions.
- **Course mastery:** phrases that have reached Strong or Mastered.
- **Level ring:** XP-based application level, separate from language certification.

## Scheduling

Low scores can return after about ten minutes. Successful reviews advance through approximately 1, 3, 7, 14, and 30 days. An item must succeed repeatedly; one perfect answer does not create permanent mastery.
